You need to install the Stylus UserCSS Manager extensions for your browser to use this UserCSS. You can install it here:
- [Stylus for Chrome](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne)
- [Stylus for Firefox](https://addons.mozilla.org/en-US/firefox/addon/styl-us/)

# Install

<Steps>

1. Download the compile Stylus export file from the releases: [`import.json` (download)](https://github.com/tathyagarg/handdrawn/releases/download/all-styles/import.json)
2. Open the Stylus extension and click on "Manage"
3. Click on "Import" and select the downloaded `import.json` file

</Steps>
