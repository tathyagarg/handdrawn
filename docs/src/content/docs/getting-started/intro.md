  # Handdrawn Userstyles
</div>

Handdrawn Userstyles is a collection of themes in a mouse-handdrawn aesthetic for your favorite websites. The themes are created using CSS and can be easily installed using a userstyle manager like Stylus.

## Supported websites

The currently supported list of websites is quite small given that the project is still in its early stages, but more themes will be added in the future. The currently supported websites are:

- [X](https://x.com/)
- [ChatGPT](https://chatgpt.com/)
